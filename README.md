# Деберц — лічильник

Лічильник для карткової гри **Деберц** (харківські правила) з онлайн-кімнатами для двох і більше гравців і вбудованим довідником правил з ілюстраціями.

## Можливості

- **Рахунок** роздач, комбінації (терц / полтинник / сотня / марʼяж), капот, лижа, недобір, деберц.
- **Історія** і **статистика** партії.
- **Онлайн-кімната**: один створює публічну або приватну кімнату, другий заходить за кодом (або посиланням `?room=КОД`). Рахунок, історія і налаштування синхронізуються в реальному часі.
- **Правила** з SVG-ілюстраціями карт і схем (темна і світла теми).
- Експорт / імпорт партії у JSON.

## Запуск

Гра — один файл `index.html` (без збірки). Онлайн потребує невеликого сервера з `server/`.

```bash
cd server
npm install
npm start
```

Відкрийте http://localhost:8080 — гра і онлайн працюють з одного сервера.

## Онлайн-режим

1. Вкладка **🌐 Онлайн** → вкажіть ім'я, назву кімнати і тип (публічна / приватна) → **Створити кімнату**.
2. Надішліть код (або посилання «Копіювати посилання») другому гравцеві.
3. Другий гравець вводить код на вкладці **Онлайн** → **Увійти**.

Публічні кімнати видно в списку на вкладці «Онлайн». Приватні — лише за кодом.

> Примітка: поточний рахунок кімнати зберігається на сервері, доки є хоча б один учасник і до 30 хв після виходу останнього.

### Деплой (щоб грати з різних пристроїв)

Для гри з різних мереж сервер має бути доступний з інтернету. Він потребує постійного процесу (WebSocket), тому підходять хостинги на кшталт Render, Railway, Fly.io або власний VPS: команда запуску `npm start` у папці `server/`, порт береться зі змінної `PORT`.

Гру можна віддати статично (наприклад, GitHub Pages), а в полі **«Адреса сервера»** вказати адресу розгорнутого сервера. Адреса запам'ятовується на пристрої.

## Структура

```
index.html        — гра (React через CDN, без збірки)
server/server.js  — сервер кімнат (WebSocket) і статика
server/package.json
```

## Обмеження

- Синхронізація «останній запис перемагає»: одночасні зміни з двох пристроїв можуть перезаписати одна одну.
- Один браузер = один учасник кімнати. Дві вкладки в одному браузері замінюють одна одну.
