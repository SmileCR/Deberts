# Деберц — лічильник

Лічильник для карткової гри **Деберц** (харківські правила) з онлайн-кімнатами для двох і більше гравців і вбудованим довідником правил з ілюстраціями.

## Запуск

Гра — https://smilecr.github.io/Deberts/

## Онлайн-режим

1. Вкладка **🌐 Онлайн** → вкажіть ім'я, назву кімнати і тип (публічна / приватна) → **Створити кімнату**.
2. Надішліть код (або посилання «Копіювати посилання») другому гравцеві.
3. Другий гравець вводить код на вкладці **Онлайн** → **Увійти**.

Публічні кімнати видно в списку на вкладці «Онлайн». Приватні — лише за кодом.
